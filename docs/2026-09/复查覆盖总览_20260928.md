## 三、域外第一块：hook 显示捕获层（最大盲区）

`libop/hook/` = **128.0 KB / 28 文件**，是 `binding`（28.6 KB）的 **4.5 倍**，但**不在 11 域里**——"后台"通常只算绑定会话状态机。

| 子模块 | 文件 | 状态 |
|---|---|---|
| D3D9Capture / D3D10Capture / D3D11Capture / D3D12Capture | 8 | D3D12 曾修 P0 野指针 + 09-08 自建 `d3d12_target.exe` 冒烟；**D3D9/10/11 无真机闭环记录** |
| OpenGLCapture | 2 | **无真机闭环记录** |
| DisplayHook / ApiResolver | 4 | 只有 L2 竞争修复（`8bec55e`） |
| InputHook / InputHookClient | 4 | 输入侧较厚（`bb98e92`/`371`） |
| MinHookRuntime / kiero2 | 3+ | 静态链接化后未再核查 |
| HookExport / HookProtocol / SharedFrame | 5 | 协议层，间接覆盖 |

**关键缺口：整个 hook 层在 `tests/` 里零专测**（`mouse_keyboard_test` 只 include 了 `HookProtocol.h` 供输入侧用；`op_algorithm_windows_test.cpp:392` 里的 `"opengl"` 只是显示模式字符串）。渲染捕获 hook 的验证全部依赖 09-08 那一次一次性载体冒烟。

**配套：渲染后端覆盖**

| 后端 | 支持 | 验证 |
|---|---|---|
| GDI / GDI2 / DX2 | ✅ | 09-19 修 DirectComposition 全黑（7 目标 × 4 模式矩阵） |
| D3D9 / 10 / 11 | ✅ 代码在 | ❓ 无闭环 |
| D3D12 | ✅ | ✅ 09-08 |
| OpenGL | ✅ 代码在 | ❓ 无闭环 |
| **Vulkan** | **❌ 全库零支持**（grep `vulkan` 空） | — |

Vulkan 是近年新游戏的默认后端之一，当前无任何可用截图模式。

## 七、遗漏清单与建议优先级

### 明确遗漏（建议补做）

| 优先级 | 项 | 理由 | 成本 |
|---|---|---|---|
| ★★★ | **hook 渲染捕获真机矩阵**：D3D9 / D3D10 / D3D11 / OpenGL 各选一个真实目标 | 后台截图是核心卖点，却是覆盖最薄的一块（128KB 零专测） | 中（需真机 + 各后端载体） |
| ★★★ | **Vulkan 捕获支持评估** | 现在完全为零，新游戏不可用 | 高（新实现） |
| ★★ | **OPTool 追平 09-28 新 API**（11 个） | 内核已有能力，工具无入口，验证与自用都受阻 | 低（P/Invoke + 控件） |
| ★★ | **COM 出口补测**（易语言 / VBScript 口径） | 真实用户群入口，专测仅 1.9KB，已有两次出参 bug 前科 | 低-中 |
| ★★ | **多开 + 长稳基准** | 多开是购买理由，只有代码审查无实测；长跑无 RSS 曲线 | 中 |
| ★ | **go 绑定编译验证** + **CMake 64 位判定修复** | 工程化欠账，防复发 | 低 |
| ★ | **绑定模式 340 组合矩阵化** | 逐格验证工作量大，可按"有代表 + 失败显式"折中 | 中 |

### 可不做（按"够用"原则）

- **YOLO 精度验证**：等可用模型；当前只有形状推断/NMS/拒绝语义用例
- **性能基准全表**：OCR 单点已够；QPC 分段计时收益不明
- **反检测 / 杀软评估**：超出插件层可控范围

### 已知且已接受的遗留（记录，不排期）

1. `FindPic` 的 `delta_colors` / 透明色语法与 `FindColor` 颜色串语义未对齐（`OP_Master...20260916.md` G 域硬伤 #6，🔴 仍未核）
2. `FindColorBlock` 族不接去噪（判定为设计取舍，待文档化）
3. `FindColorBlock` 参数顺序 `count,height,width`（确认属实，易误用）
4. `GetDisplay()` 死代码（有实现、契约无声明、零调用者）
5. dx 门槛 B：目标须已加载 `dinput8.dll`（增强而非必需，降级为文档化）
6. `RealPhotoTemplateCases` / `GameSceneTemplateCases` 素材不入库，其他环境 clone 后 5 用例仍 SKIP（跑 `make_screen_assets.py --recapture` 可解）
