
脚本行为（display=`normal` 与 `gdi` 各一轮）：
1. 自建白底 Tk 窗口 320×200 → `bind_window(hwnd, <display>, windows, windows)` → 整窗 `capture` + 中心 `get_color`

## 3. B 组：OCR 三件套 + 白名单 + 耗时（同脚本 A 组后自动执行）

窗口显示黑体大字 **`许愿树[320,-778]12345`**（白底黑字，含中文/数字/`[ ] , - +`）。

| 验证项 | API | 判定 |
|---|---|---|
| 单行快路径识别 | `autoocr_line(0,0,w,h,"000000-303030",0.7)` | 结果含 `许愿树`、`320`、`-778`、`12345`（白名单生效，无拉丁乱入） |
| 耗时 | 同参数循环 20 次 | **avg ≈ 9–13ms/帧**（PP-OCRv4 rec 单行量级）；>30ms 需查引擎是否走了 det 慢路径 |
| 结构化输出 | `autoocr_ex(...)` | `count≥1`；items 为 `x1,y1,x2,y2,conf,text`，单行文本场景仅 1 条 |
| 文件路径对照 | capture 存 BMP → `ocr_from_file(bmp,...)` | 与绑定路径结果一致（引擎/白名单跨入口一致） |

**判定**：引擎 `set_ocr_engine("onnx","", "--charset=@zh0123456789[],-+")` 返回 1；文本三项命中；耗时达标。
若需验证"拉丁字母被屏蔽"，把 charset 换成 `--charset=@zh` 再跑一遍，`ABC` 之类不应出现。
