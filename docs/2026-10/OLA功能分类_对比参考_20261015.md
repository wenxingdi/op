## 高级版收费功能（87 个接口 + 绑定参数 + 内存 mode）

**绑定参数（BindWindow/BindWindowEx 内启用）**：display="vmware" 虚拟机截图（需管理员）；
mouse 含 "dx.mouse.vmware" 虚拟机鼠标穿透（vm16/vm17）；keyboard 含 "dx.keypad.vmware"
虚拟机键盘穿透；public 含 "ola.public.memory.protect"/"protect2" 无痕绑定。

**内存读写 mode（SetMemoryMode）**：4 物理内存读写 / 5 无附加读写 / 6 无附加物理读写 /
7 特殊模式（旗舰版未开放）/ 8 VT特殊模式（旗舰版未开放）。

**高级版接口分布**：
- 内存：HookRemoteApi / UnhookRemoteApi
- 注入：Inject
- 驱动内核：文件保护驱动系 12 个 + VipProtect 高级保护系 12 个 + HideProcess +
  VT 伪写系 6 个（共 31 个）
- DMA：全部 50 个

## 初步对比方向（待与 op-master 逐项核对后填充）

> 以下仅为快速印象，正式对比需逐模块核对 op 的 C API 导出清单。

- **op 有而 OLA 无**：字库二值化 OCR（FindStr/OcrFromDict 类，op 的传统强项）、
  键鼠后台 dx 系参数体系（ola 亦有 vmware 穿透）、内存 AsmCall 外的主从同步录制回放差异待核。
- **OLA 有而 op 大概率无（新增候选）**：
  1. 视频处理模块（≈40 接口：摄像头/视频文件读写/场景检测/运动检测）——op 完全缺失的整模块；
  2. 屏幕绘制 DrawGui*（≈45 接口）——op 无屏幕绘制层；
  3. 数据库 SQLite（33 接口）+ Config 配置项——op 无；
  4. JSON / XML 模块——op 无（脚本层通常自带，优先级低）；
  5. 注册表模块（≈28 接口）——op 无；
  6. 加密模块（RSA/AES/MD5/SHA/HMAC/Base64/PBKDF2）——op 无；
  7. 消息传递 PubSub/MQ、远程调用、TCP 服务端——op 无；
  8. 图像处理增强：形态学系（顶帽/黑帽/开闭运算/骨架化）、Canny/高斯/锐化、
     二维码生成解析、图像拼接 Stitch、SSIM/MSE/直方图比较、连通域——op 的 opencv
     桥有部分（形态学/边缘），二维码/拼接/SSIM 待核；
  9. 图像数据库（ola 私有格式，参考价值低）；
  10. 快捷键监听、日志系统——工程辅助类，价值中；
  11. 驱动内核/DMA/VT——与 op 定位差异大（硬件级），不建议跟进；
  12. YOLO 分类/分割/姿态/旋转框（op 仅检测）——若升级 YOLO 引擎可考虑。
