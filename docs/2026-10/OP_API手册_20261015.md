# OP Master API 手册（2026-10-15）

> 数据源：`include/op_c_api.h`（C ABI 导出契约，302 个 OP_CALL 导出，含第十九/二十批新增 23、第二十一~二十四批新增 16）。
> COM（op.idl 302 id）与 SWIG/python 绑定以此为准对齐；废弃别名单独标注。
> 本手册是功能对比基线，新增/废弃接口时请同步更新。
