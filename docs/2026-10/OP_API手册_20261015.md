# OP Master API 手册（2026-10-15）

> 数据源：`include/op_c_api.h`（C ABI 导出契约，263 个 OP_CALL 导出）。
> COM（op.idl 268 id）与 SWIG/python 绑定以此为准对齐；废弃别名单独标注。
> 本手册是功能对比基线，新增/废弃接口时请同步更新。

## 模块总览

| 分区 | 导出数 | 功能域 |
|---|---|---|
| Lifecycle | 2 | 对象创建/销毁 |
| Basic | 23 | 版本/路径/错误/插件注入/图片缓存/A* 寻路入口/截图预处理 |
| Algorithm | 2 | A* 寻路（点阵版）/最近坐标 |
| Window and process | 45 | 窗口查找枚举/窗口属性读写/进程信息/剪贴板/字符串发送/运行程序 |
| System misc | 11 | 屏幕参数/DPI/时间/蜂鸣/随机数/机器码/管理员检查 |
| Background binding | 10 | 后台绑定 dx 系/降载/输入通道开关 |
| Mouse | 35 | 移动（含轨迹/平滑）/三键+X1X2/滚轮/延迟 |
| Keyboard | 10 | 按键（码/字符/字符串）/等待按键/延迟 |
| Image and color | 24 | 找图找色找块找线/取色/截图数据/图片缓存 |
| OpenCV | 36 | 模板管理/预处理（灰度/二值/边缘/形态学/细化）/多策略匹配 |
| OCR | 48 | 引擎选择/字库维护/免字库 OCR 三族/FindStr/词提取预览 |
| Memory | 15 | 进程内存读写/特征码搜索/模块基址 |

**命名族说明**：免字库 OCR 现行名 = `OcrAuto`（原图）/ `OcrAutoColor*`（按色二值化）/
`AutoOcr`（归一入口，推荐）；`OpAutoOcrLine/Ex/FromFile` 为旧名废弃别名（保留转发）。
`OpOcrAutoFromFile` 同理为旧名别名。
