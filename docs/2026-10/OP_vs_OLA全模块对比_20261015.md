# OP vs OLA 全模块功能对比与新增建议（2026-10-15）

> 左栏：OLA 功能面（源：`OLA功能分类_对比参考_20261015.md`，31 模块约 700 接口）。
> 右栏：op 现状（源：`OP_API手册_20261015.md`，261 个 C API 导出）。
> 优先级：**P1** = 常用且低门槛，建议近期做；**P2** = 常用，中低门槛；
> **P3** = 方向性/按需；**—** = 不跟进（定位差异或 SaaS 特有）。
> 与 `OLA对比_五域功能_20261015.md`（五域深挖 13 项）互补：那份讲深，这份求全。

## 逐模块对比

### 窗口（OLA ≈50 / op 45）
op 已覆盖：查找枚举系、属性读写、SendString/Ime、SendPaste、SetClipboard、
LockWindowPosition/Size、DisableMinMax、SetIme、SetWindowTransparent、RunApp。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| GetScaleFromWindows / GetWindowDpiAwarenessScale（窗口 DPI 缩放） | 新增 GetWindowScale：高 DPI/缩放显示下坐标换算是刚需，op 的 GetDPI 是系统级，缺窗口级 | **P1** |
| EnumWindowSuper / FindWindowSuper（特殊窗口） | 前台钩子类小众需求 | P3 |
| SendPaste2/3、SendString2/Ex | op SendPaste/SendString 已覆盖主流程 | — |
| GetProcessIconImage | 小众 | P3 |

### 鼠标（OLA ≈30 / op 35）
op 已覆盖：三键+X1X2 全点击系、MoveTo/Ex/Smooth、MovePath/DragPath（轨迹）、
SetMouseTrajectory、GetCursorPos/Shape、滚轮/横滚。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| GetCursorImage（取鼠标图标句柄/位图） | 有特征码（Shape）场景外，图标比对是补充手段 | P2 |
| MousePosCallback 位置回调 / EnableMouseAccuracy | 录制回放类配套 | P3 |
| GenerateMouseTrajectory 渐开线轨迹 | op 轨迹已内置（贝塞尔+噪点），渐开线是另一流派 | — |

### 键盘（OLA ≈15 / op 10）
op 已覆盖：KeyPress/Down/Up ×（码/字符/字符串）、WaitKey、SetKeypadDelay。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| **KeyPressHotkey 组合键**（如 "ctrl+alt+a"） | op 无组合键语法（五域对比已实证），脚本要自己拼 Down/Up 序列，易错（顺序/超时） | **P1** |
| VirtualKeyCodes 键码表 | 文档即可，不用接口 | — |

### 后台绑定（OLA 在窗口模块内 / op 10）
op：BindWindow(Ex)/UnBind/IsBind/GetBindWindow/LockInput/DownCpu/
SetDxAttr/GetDxAttr/GetDisplayMethod——dx 输入通道开关体系完整。
OLA 的 vmware 虚拟机穿透/display="vmware"：属硬件级差异，**不跟进（—）**。

### 图色与图像处理（OLA ≈110+ / op 24+36）
op 已覆盖：找色/多点色/找块/找线全族、CmpColor、取色、截图数据系、
模板缓存、灰度/二值/边缘/形态学/骨架化/细化/轮廓/连通域/直方图/锐化模糊/
多策略匹配（特征/边缘/形状/旋转/多尺度）。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| **二维码 CreateQRCode / DecodeQRCode** | 自动化里扫码/生成码很常见（登录、验证）；OpenCV 有 QRCodeDetector 可直接桥 | **P1** |
| RotateImage / Flip 旋转翻转 | 匹配前处理常用（MatchTemplateRot 只解决匹配环节，不输出旋转图） | P2 |
| IsDisplayDead 卡屏检测 | 有 GetFPS 可推导但一键检测更方便（游戏卡死监控刚需） | P2 |
| RGB2Hex/HSV 颜色转换 | op 颜色串本就是 "RRGGBB-DRDGDB"；HSV 对按色找图有补充价值 | P2 |
| ImageToBase64 / Base64ToImage | 配合图传场景；HTTP 模块已砍，优先级降 | P3 |
| 形态学顶帽/黑帽/开闭、Canny | OpCvMorphology/ToEdge 近似覆盖 | — |
| ImageStitch 全景拼接、SSIM/MSE/直方图比较 | 小众 | P3 |
| SetPixel/CreateImage/绘制在图上 | 与屏幕绘制二选一 | P3 |

### 图像识别（OLA ≈20 / op 在图色+OpenCV）
op FindPic 全族 + CvMatch* 多策略已覆盖 Match/Find 系主体。SSIM/IsSameImage P3。**—**

### 视频处理（OLA ≈40 / op 0）
整模块缺失：视频文件/摄像头读写、帧提取、场景/运动检测。
OpenCV videoio 可桥，但接口面大、需求密度低。**P3 方向**（先只做
OpenVideo/ReadFrameAtTime/ExtractThumbnail 三件套亦可）。

### OCR（OLA ≈45 / op 48）
op 反超强项：字库系（SetDict/AddDict/SaveDict/FetchWords/FindStr…）OLA 无对等深度。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| OcrWarmupModel 模型预热 | 首次推理秒级延迟在找字场景可感知，预热一次即可 | P2 |
| FastNumberOcr 快速数字 | 近似被 OcrAutoColorLine（单行直 rec）覆盖 | — |
| 模型加密 OcrEncryptModel | 商用分发场景 | P3 |

### 内存（OLA ≈50 / op 15）
op 已覆盖：Int/Float/Double/String/Data 读写、特征码搜索（?? 通配）、模块基址。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| GetModuleSize 模块大小 | 基址+大小是读模块的完整前置，一条 VirtualQuery 链 | P2 |
| VirtualAllocEx / VirtualProtectEx | 写代码/改页保护是修改系刚需，Win32 直包门槛低 | P2 |
| GetModuleInfoList 枚举模块 | 遍历模块找基址的常规操作 | P2 |
| HookRemoteApi / GetRemoteApiAddress | 内核/高级版领地 | — |
| DMA / 物理内存 mode 4-8 | 硬件级差异 | — |

### 汇编（OLA 3 / op 0）
AsmCall（执行汇编）门槛高（内嵌汇编引擎）；Assemble/Disassemble 需
keystone/capstone 依赖。**P3**。

### 算法（OLA ≈30 / op 9）
op 已有：A*（双形态）/LOS 平滑/RDP 抽稀/最近点/多边形判定/随机数。
OLA 图论系（建图/最短路/生成树）游戏自动化用得少；SortPosDistance 脚本易做。**—**

### 文件（OLA 21 / op 0）⚠️ 全模块缺失
op 无任何文件接口（脚本读配置/写日志/找文件全靠外部）。
| 建议整组新增（12 核心） | 优先级 |
|---|---|
| FileExists / CreateFolder / DeleteFolder / GetFileList（通配遍历）/ CopyFile / MoveFile / DeleteFile / GetFileSize / ReadFileString / WriteStringToFile / GetFileName（路径解析）/ ToAbsolutePath | **P1** |
其余（CreateFile 句柄系/ReadBytes）P2 可后补。纯 Win32/STD 实现，门槛低。

### 系统（OLA ≈20 / op 11）
op 已有：Delay/Delays/GetTime/Beep/GetDPI/IsElevated/GetMachineCode/屏幕参数。
| 缺口 | 建议 | 优先级 |
|---|---|---|
| **TerminateProcess / TerminateProcessTree** | 脚本杀进程/清环境刚需；**进程树终止逻辑在 `ipc/Pipe.cpp::terminate_process_tree` 已有现成实现可复用** | **P1** |
| SendDropFiles 拖拽文件到窗口 | 少数业务场景（游戏导入文件） | P2 |
| GetCommandLine 进程命令行 | 排查多开/启动参数常用 | P2 |
| CheckUAC/SetUAC、字体平滑、任务栏图标 | 小众 | P3 |

### 注入（OLA 3 / op 1）
op InjectDll ✓。InjectFromBuffer/InjectFromUrl P3（DllInjector 已内存注入能力可扩）。

### 屏幕绘制（OLA ≈45 / op 0）
调试框/结果标注是自动化高频诉求（找图结果可视化）。建议先做最小组：
DrawGui Rectangle/Circle/Line/Text + SetVisible/ClearAll（透明叠加层）。
**P2**，门槛中（需 overlay 窗口管理）。

### 快捷键（OLA 12 / op 0）
全局热键注册（脚本启停）P2，门槛中（RegisterHotKey 消息循环）。

### 加密（OLA ≈18 / op 0）
| 建议 | 优先级 |
|---|---|
| MD5 / SHA1 / Base64（WinCrypt 直包，验证/签名场景常用） | P2 |
| AES / RSA / HMAC | P3 |

### 注册表（OLA ≈28 / op 0）
脚本语言大多自带注册表能力，接口性价比低。**P3**。

### JSON / XML（OLA ≈70 / op 0）
脚本层自带解析。**P3**。

### 网络 / 远程调用 / 消息传递（OLA ≈40 / op 0）
HTTP 模块 2026-09-18 已决策移出（OCR/YOLO 不走远程后端）；TCP/PubSub/MQ 同口径。**P3**。

### 数据库 / 图像数据库 / Config（OLA ≈50 / op 0）
SQLite 嵌入门槛中，脚本自带 sqlite3。**P3 方向**。

### 键鼠同步（OLA 7 / op 0）
录制回放 + 监听回调，门槛中高。**P3 方向**。

### 日志（OLA ≈35 / op 0）
op 有内部 setlog；对外分级日志 API 价值一般（脚本自带）。**P3**。

### 授权管理 / 软件自更新 / 驱动内核 / DMA
OLA SaaS 与硬件级领地，op 定位不同。**— 不跟进**。

### YOLO（OLA 35 / op 3）
op 现只有检测（Detect ×3 形态）。分类/分割/姿态/旋转框依赖 ONNX 引擎能力
升级，非接口层面工作。**P3 方向**。

## 新增建议汇总（按优先级）

### P1——常用且低门槛（~~建议近期立项~~ 已于 2026-10-15 第十九批全部落地）
| # | 功能 | 接口草案 | 依据 | 状态 |
|---|---|---|---|---|
| 1 | 文件模块核心组 | OpFileExists/CreateFolder/DeleteFolder/GetFileList/CopyFile/MoveFile/DeleteFile/GetFileSize/ReadFileString/WriteStringToFile/GetFileName/ToAbsolutePath | op 全模块缺失，脚本最高频外部依赖 | ✅ 已落地（第十九批） |
| 2 | 组合键 | OpKeyPressHotkey("ctrl+alt+a") | 五域对比已实证缺失，脚本拼 Down/Up 易错 | ✅ 已落地（第十九批） |
| 3 | 窗口 DPI 缩放 | OpGetWindowScale(hwnd)（含 awareness） | 高 DPI 下坐标换算刚需 | ✅ 已落地（GetWindowScale，第十九批） |
| 4 | 进程终止 | OpTerminateProcess(pid)/OpTerminateProcessTree(pid) | Pipe.cpp 已有树终止实现可复用 | ✅ 已落地（第十九批） |
| 5 | 二维码 | OpDecodeQRCode(img)/OpCreateQRCode(text) | OpenCV QRCodeDetector 可直桥 | ✅ 已落地（DecodeQRCode/DecodeQRCodeFromFile/CreateQRCode，第十九批） |

### P2——常用，中低门槛
| # | 功能 | 说明 |
|---|---|---|
| 6 | 内存三件套 | OpGetModuleSize / OpVirtualProtectEx / OpVirtualAllocEx（+OpGetModuleInfoList） |
| 7 | 图像变换 | OpCvRotate / OpCvFlip |
| 8 | 卡屏检测 | OpIsDisplayDead（区域帧哈希比对，截屏链已有数据） |
| 9 | 摘要/编码 | OpMd5 / OpSha1 / OpBase64（WinCrypt 直包） |
| 10 | 拖拽文件 | OpSendDropFiles(hwnd, files) |
| 11 | 鼠标图标 | OpGetCursorImage |
| 12 | OCR 预热 | OpOcrWarmup（懒加载引擎提前触发一次推理） |
| 13 | 屏幕绘制最小组 | OpDrawRect/Line/Text + OpDrawClear（调试可视化） |

### P3——方向性，按需再动
视频模块、YOLO 分类/分割/姿态、SQLite/Config、JSON/XML、TCP/HTTP、
注册表、全局热键、键鼠录制回放、AsmCall、对外日志 API、图像拼接/SSIM。

### 不跟进
授权/自更新/DMA/驱动内核（OLA SaaS 与硬件级领地）；SendString 系冗余变体。
