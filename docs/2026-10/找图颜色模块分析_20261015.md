# 找图/颜色模块分析（2026-10-15，逐模块专项第 2 弹）

> 范围：`libop/image/` 的找图（FindPic 系）与颜色（FindColor 系）链路 +
> 公共基础设施（颜色串解析、二值化、图片缓存、投影切分）。
> OCR 识别本体（`_bin_ocr` 双实现、免字库引擎调用）在本文件内但**前三批刚大修过**，
> 本轮仅列观察项，不并入处置。
> 分析方法同第 1 弹（后台绑定）：先出清单 → 用户确认 → 再实施。

## 结构总览

```
服务层 ImageSearchService（1411 行）
  ├─ 找图：FindPic / FindPicEx → files2mats（进程级缓存+模板预建）→ FindPicTh / FindPicExTh
  ├─ 颜色：FindColor(Ex) / FindMultiColor(Ex) / GetColorNum / CmpColor
  │        → str2colordfs（颜色串解析，支持 "颜色-偏色|..." 与 "@背景色"）
  │        → prepared_color_dfs（隐式偏色按 sim 展开）→ for_each_scan_point（8 向扫描序）
  ├─ 块查找：FindColorBlock(Ex/ExS) → str2binaryfbk → _binary + record_sum 积分图
  ├─ 字模：FetchWord(FromBinary) / ExtractWordRects(Ex) / FetchWords(ByRects/Ex)
  │        → str2pointbinaryfbk → ApplyBinaryPreprocess（孤立点/小组件/桥接三级去噪）
  └─ 公共：g_pic_cache（shared_mutex，500 条上限满即清空）、g_file_dicts、for_each_dict_line

算法层 ImageSearchAlgorithms（1793 行）
  ├─ 扫描骨架：for_each_scan_point（dir 0-8，dir=4 中心优先用堆按距离生成）
  ├─ 匹配：real_match（灰度+积分图快筛）/ trans_match（透明图前景点对）
  │        + build_pic_match_template（缓存灰度/透明点，进程级复用）
  ├─ 二值化：bgr2binary / bgr2binarybk（@背景色反白）；投影切分 binshadowx/y + bin_image_cut
  └─ OCR：bin_ocr → _bin_ocr（精确/模糊双实现，~120 行结构重复）
```

整体评价：找图/颜色主链路近年加固到位（预处理模板单源化、扫描序骨架、
积分图快筛、进程级缓存带互斥与上限），**无双份实现漂移隐患**；
问题集中在**返回上限截断不一致（bug 族）**、**少量死代码**、
**免字库 OCR 调用样板重复**三处。
