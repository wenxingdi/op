## 三、发现的四类问题

### 问题 1：v4 快档在长行上碎片化（最显著）

`13.bmp` 任务追踪面板，v6 输出 **17 行完整**，v4 输出 **24 行**，把长行拆成多块：

| v6（正确） | v4（碎片化） |
|---|---|
| `击倒青螺山追踪者（2849m）0/5` | `击倒青螺山追踪者（2849m）0` + `0/5` |
| `击倒林掌山吼兽（963m）0/5` | `击倒林掌山吼兽（963m)0` + `0/5` |
| `击倒沼泽猎犬（718m）0/5` | `击倒沼泽猎犬（718m）` + `0/5` |

**根因**：v4 字典仅 6623 字，长行识别置信度低，det 框更碎。这是 v4 快档的固有限制，非 bug。

**建议**：**长行/密集文本场景固定用 v6，不要用 v4。**

### 问题 2：小字号单行（15/18 号）识别失败

`15.bmp`（165×23）：
- v6: `[CT8I-680I-]号翔漏` (conf 0.792) — 完全错误
- v4: `割喉候` — 只出 3 字（疑似应为「割喉者」）

`18.bmp`（166×23）：
- v6: `[9818]旱` (conf 0.737) — 严重丢失
- v4: `青螺山死门[-8815-1808]` — 正确

**关键发现**：这两张图 **conf 明显偏低（0.737/0.792）**，而其余正确样本 conf 均在 0.9 以上。
**置信度是可靠的可信度指标**——低于 0.85 时应视为不可信。

同时说明 v6/v4 **在不同样本上互有胜负**，不是 v6 永远更好。

### 问题 3：数字与标点易错（低影响）

| 样本 | 正确 | v6 | v4 |
|---|---|---|---|
| 11 | `[1448,1365]` | `[1448,1365]` ✅ | `[14481365]` ❌ 丢逗号 |
| 14 | `[-1166-1809]` | `[-1166-1809]` ✅ | `[-1169-1809]` ❌ 6→9 |

坐标数字的千位分隔符和小数字符是高频错误点。

### 问题 4：颜色路径多数场景不可用

对 15/18/12 号尝试传色（自动提取主色 + 白/红/绿）：

| 样本 | 传色结果 |
|---|---|
| 15 | 全部 0 行或 `台0` |
| 18 | 全部 0 行或 `青苑1136` |
| 12 | 全部 0 行 |
| 11 | `33EE33`（绿）→ `月龙村[1448,1365]` ✅ 与不传色一致 |

**结论**：这批素材是**游戏截图（彩色背景、大量渐变与描边）**，多数不适合二值化。
仅 11 号的纯绿字能被正确分离。**建议默认不传色，用原图直识。**
这与交接记录《B10 结论》一致：「≤14px 密集字，二值化切边导致丢字，必须走原图直识」。

## 五、耗时数据

| 场景 | v6 耗时 | v4 耗时 |
|---|---|---|
| 单行小图（155×33 ~ 207×33） | 33~72 ms | 21~40 ms |
| 多行中等图（259×208） | 361 ms | 584 ms |
| 多行大图（291×430） | 921 ms | 1374 ms |
| 密集长行（220×236，17~24行） | 701 ms | 1800 ms |

**v4 在大图上反而更慢**（1374ms vs 921ms），因为它切出的框更多（24 vs 15 行），
rec 次数增加。**v4 的「快档」优势只在单行小图上成立（21~40ms vs 33~72ms）。**

## 六、可执行的结论与建议

### 使用策略

| 场景 | 推荐档位 | 说明 |
|---|---|---|
| 单行小图、坐标类（<210px 宽） | **v4** | 快 30~50%，准确率接近 |
| 多行长文本、任务列表 | **v6** | v4 会碎片化，实测 24 行 vs 17 行 |
| 密集小字（12~16px） | **v6 + 不传色** | v4 漏字严重，传色会丢更多 |
| 彩色游戏背景 | **不传色** | 二值化切边破坏抗锯齿文字 |

### 置信度阈值

**建议 `conf < 0.85` 的结果标记为不可信**。实测：
- 正确结果 conf 普遍 ≥ 0.90
- 严重错误的结果 conf 为 0.737 / 0.792

`is_partial` 字段这批素材全部为 false（无贴边截断）。

### 已知缺陷（非本轮引入）

1. **v4 长行碎片化** — 字典小（6623 vs 18708）导致，固有局限
2. **数字千位符易错** — `1448,1365` → `14481365`
3. **小字号单行不稳定** — 15/18 号两档互有胜负，需按场景选档
