### 2. sync_op_dll.py 同步缺口 ✅ 已修（脚本）

**问题**：脚本此前只同步 OPTool 三处 Dll 目录；op 仓库 `bin/x64` 与
Python 绑定包 `bindings/python/op/bin/x64` 里的 DLL 全靠手动同步，
python312 重编后就发生过一次漂移（手动补的）。AGENTS.md/CLAUDE.md 声称的
"三处同步"与实际行为不符。

**修复**（`D:\AutoPro\OPTool\sync_op_dll.py` 步骤 6）：

- x64 集（op_c_api_x64.dll / op_x64.dll / onnxruntime.dll /
  onnxruntime_providers_shared.dll / tools.dll）→ `op/bin/x64` 与
  `bindings/python/op/bin/x64`，sha1 增量；
- x86 对（op_c_api_x86.dll / op_x86.dll）→ `op/bin/x64`（x86 构建目录存在时）；
- 脚本头说明同步更新。

验证：实跑一次，除自动补齐 Python 包内缺失的 tools.dll 外全部 sha1 跳过，行为符合预期。

### 3. api.py docstring 与实现不符 ✅ 已修（注释）

`bindings/python/op/api.py` 五处 docstring 与实际行为不符（注释误导调用方）：

| 函数 | 修前（错） | 修后（实） |
|---|---|---|
| `find_str_mem` | `json_targets 形如 {"strs":["主城"],"color":"FFFFFF-101010"}` | JSON **数组**：`["主城"]` 或 `[{"text":...,"match":"exact",...}]`；返回 JSON 结果串 `{"targets":N,...,"results":[...]}` |
| `find_pic_ex_from_mem` | 返回 JSON 串 | 大漠坐标串 `"x,y,index\|x,y,index\|..."` |
| `find_color_ex_from_mem` | 全部命中 JSON | 大漠坐标串 `"x,y\|x,y\|..."` |
| `find_multi_color_ex_from_mem` | 全部命中 JSON | 大漠坐标串 `"x,y\|x,y\|..."` |

依据：参数解析见 `ImageSearchService::find_str_batch`（要求 Type::Array）；
坐标串拼接见 `ImageSearchAlgorithms` 各 `*Ex` 的 `retstr += to_wstring(x) + L"," + to_wstring(y) + L"|"`。

`find_color_block_ex_from_mem` 的 docstring 未涉及返回格式误述，未改。
