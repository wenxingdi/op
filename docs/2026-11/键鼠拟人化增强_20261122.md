# 键鼠拟人化增强（第四十七批，2026-11-22）

> 来源：对 `libop/input/` 的拟人化设计二次审查（7 项优化建议，全部落地）。
> 验证：全量回归 579 项 / 575 PASS（3 FAILED = 已知 WGC 抓屏环境项；1 SKIP = FurMark 环境项）。

## 背景

既有拟人化基础：三次贝塞尔轨迹 + smoothstep 速度曲线 + 抖动弯曲、每步 ±30% 时间抖动 +
5% 概率微停、`DelayJitter` ±40% 点击/按键间隔、`thread_local mt19937`（random_device 播种）。

审查发现的薄弱点与本轮改动一一对应：

| # | 问题 | 改动 | 位置 |
|---|---|---|---|
| 1 | DragPath 段内线性插值，直线拖拽是强机器特征 | 段内改走 `build_mouse_path`（贝塞尔+曲线族），多段时长均摊 | `WinMouse::DragPath` |
| 2 | 全网共用一条 smoothstep 曲线 | 3 种缓动随机选（smoothstep / quintic smootherstep / 正弦 in-out），`apply_easing(kind, t)` | 匿名命名空间 |
| 3 | 两控制点独立随机弯曲，可能反向抵消拉成直线 | 同号相关弯曲：同一符号 × 0.5~1.0 幅值；贴合真人单次移动朝一侧弧线，且给测试"必弯"下界 | `build_smooth_path` |
| 4 | 落点精确命中，无过冲 | 距离 ≥40px 时 35% 概率偏出 2~5px 后收回（15~40ms 内归位） | `WinMouse::MoveToSmooth` |
| 5 | MoveToEx 矩形内均匀分布 | 正态偏置 σ=span/3（新增 `rand_normal()`，Box-Muller 截断 ±3σ） | `random_offset` |
| 6 | 双击间隔复用单击延时（30ms 级） | 三套双击路径专属 80~150ms 随机间隔 | `human_double_click_gap_ms` |
| 7 | 键盘按住 30/10ms 偏机器 | 默认 60/60/40ms（`SetKeypadDelay` 仍可覆盖） | `AutomationModes.cpp` |

## 关键语义决策

**末端过冲不破坏"确定性轨迹"约定**：全量回归抓到既有用例
`MouseKeyTest.MouseTrajectoryJitterBendsPath` 以 `jitter=0 → 笔直轨迹` 为不变量。
最终语义：**`jitter=0` 或线性模式（mode 1）不触发过冲**——用户显式要求无随机弯曲时，
不叠加任何随机位移。默认配置（jitter=18、mode 0）正常带过冲。

## 随机数

新增 `rand_normal()`（`Utils.h/.cpp`），与 `rand_range`/`rand_unit_signed` 同走
`thread_local mt19937`（random_device 播种），跨线程序列不可复现的性质不变。

## 测试

新增 `tests/mouse_trajectory_test.cpp`（6 用例，接入 `tests/CMakeLists.txt`）：

| 用例 | 断言 |
|---|---|
| SmoothMoveEndsAtTargetWithIntermediateSteps | 终点精确命中 + 多步（非瞬移） |
| SmoothMoveProducesCurvedPath | 200px 水平移动偏离直线 ≥3px（jitter=100 理论中点偏离 ≥30px，留 10 倍余量） |
| LinearModeStillReachesTarget | 线性模式贴线（<1px），终点命中 |
| DragPathSendsDownMovesThenUp | 按下→带 MK_LBUTTON 移动→抬起时序 + 终点正确 |
| DragPathIsCurvedNotStraight | 拖拽轨迹偏离直线 ≥3px（直线拖拽是强机器特征） |
| MoveToExFavorsCenterOfRange | 300 采样 \|offset\| 均值 <40（正态 ≈27，均匀 =50），且不越界 |

说明：桩 `MouseEventWindow::ResetCounts()` 不清事件向量，用例显式
`move_events.clear()` 后再断言偏离量，避免初始定位跳点污染统计。

## 兼容性

- 无 API 面变化（全部内部行为 + 默认值）；`SetMouseTrajectory`/`SetKeypadDelay` 语义不变。
- 行为变化点（调用方无感但时序变化）：双击变慢（80~150ms 间隔）、键盘按住变长
  （60ms 级）、平滑移动末端偶发过冲。对时序敏感的旧脚本可用 `SetKeypadDelay` 调回。
